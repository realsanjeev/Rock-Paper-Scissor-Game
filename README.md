# 🎮 Rock Paper Scissors Game

A collection of Rock Paper Scissors game implementations featuring a stunning modern web interface, Python CLI versions, Tkinter GUI, and an online multiplayer version.

## 📖 About

Rock Paper Scissors is a classic hand game usually played between two people. This project showcases multiple implementations of the game, from simple command-line interfaces to a beautiful, modern web application with smooth animations and visual effects.

### Game Rules

- 🪨 **Rock** crushes **Scissors**
- 📄 **Paper** covers **Rock**
- ✂️ **Scissors** cut **Paper**

## ✨ Features

- **Smooth Animations** for all interactions and game states

## 🚀 Getting Started

### JavaScript Web Version

1. Navigate to the JavaScript directory:
   ```bash
   cd Javascript
   ```

2. Open `index.html` in your web browser:
   ```bash
   # On Linux
   xdg-open index.html
   
   # On macOS
   open index.html
   
   # On Windows
   start index.html
   ```

3. **Play the game:**
   - Click on Rock, Paper, or Scissors to make your choice
   - Use keyboard shortcuts: `R` for Rock, `P` for Paper, `S` for Scissors
   - Press `Escape` to reset the game
   - Watch your score update in real-time!

### Python CLI Version

1. Navigate to the CLI directory:
   ```bash
   cd "Game in CUI"
   ```

2. Run any of the three methods:
   ```bash
   python method1.py
   # or
   python method2.py
   # or
   python method3.py
   ```

3. Follow the on-screen prompts to play

### Tkinter GUI Version

1. Install required dependencies:
   ```bash
   pip install pillow
   ```

2. Navigate to the Tkinter directory:
   ```bash
   cd Tkinter-GUI
   ```

3. Run the application:
   ```bash
   python main.py
   ```

### Online Multiplayer Version

1. Install dependencies:
   ```bash
   cd "Online Game"
   pip install -r requirements.txt
   ```

2. Start the server:
   ```bash
   python server.py
   ```

3. In separate terminals, run clients:
   ```bash
   python client.py
   ```
